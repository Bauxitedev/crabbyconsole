# VR support

CrabbyConsole has basic VR support. To get started, run this code in your game's startup logic:
```gdscript 
CrabbyConsole.enter_vr()
```

That's all! This will create a rectangle in 3D with the console drawn on it in front of your `XRCamera3D`. To interact with it, type on your physical keyboard. (Virtual keyboards are not supported yet.) If the console isn't registering your key presses, try pressing ++tilde++ a few times first, and ensure the game's window is focused.

If the console isn't showing up, try the following:

1. Try pressing ++tilde++ a few times.
2. If you called `enter_vr()` from `_ready()` in an autoload, it may be called too early, because CrabbyConsole is still busy setting itself up. To mitigate this, you can do this in your script instead:
    ```gdscript
    CrabbyConsole.enter_vr.call_deferred()
    ```
3. If that still doesn't work, the `XRCamera3D` may not be in the right place initially, so the console may end up in the wrong spot. To fix this, try putting this in your script to wait a few frames before entering VR mode:   
    ```gdscript
    for i in 10:
        await get_tree().process_frame
    CrabbyConsole.enter_vr.call_deferred()
    ```
4. If that still doesn't work, the `world_scale` of your `XROrigin3D` may be too far away from `1`, so the console becomes too small to see. To mitigate this, try making the console 4x larger by putting this in your script:
    ```gdscript
    CrabbyConsole.enter_vr()
    await get_tree().process_frame # wait one frame for VR mode to initialize
    CrabbyConsole.eval_blocking(":cons vr scale 4")
    ```
    

!!! example "Experimental"

    VR support is experimental and subject to change. Mouse inputs are not supported yet, so you can only send keyboard events to the console.

## Resizing the console

As mentioned before, if you changed the `XROrigin3D`'s `world_scale` from its default value of `1`, the console may be too big or small. To fix that, you can run...
```
:cons vr scale 2
```
...to double the size of the console, or...
```
:cons vr scale 0.5
```
...to halve it.

### Expanding the console

Since there is no mouse support yet, the console may be too small vertically, and you can't drag the splitter to fix it. As a workaround, you can run this in the console:
```
:cons vr expand
```

Now the console will expand to fill all available vertical height.

## Camera follow

By default, the console will remain fixed in its position, regardless of where you look. To make the console follow the camera, run:
```
:cons vr follow 1
```

The console will now move with your head, so you can place it anywhere you want. To make it stop following you, run:
```
:cons vr follow 0
```

...and it will lock in place again.
