# VR support

CrabbyConsole has basic VR support. To get started, run this code in your game's startup logic:
```gdscript 
await get_tree().create_timer(1.0).timeout
CrabbyConsole.enter_vr()
```

That's all! This will wait one second, and then create a `Sprite3D` with the console drawn on it in front of your `XRCamera3D`. In other words, you'll see the console appear in front of you in VR.

??? question "Why do we need the one-second wait?"

    There are two reasons:

    1. If you call this in `_ready()` in a node that runs very early in the game's lifecycle, such as the main scene or an autoload, there is a chance you'd call `enter_vr()` on `CrabbyConsole` before it's ready, which would cause an error.
    2. In the first few frames of the game, the `XRCamera3D` is not in the right position yet, so spawning it too early would spawn the console at your feet, instead of at your head.

    The one-second wait prevents both problems (with a lot of headroom, to be more robust against e.g. long load times).

To interact with it, type on your physical keyboard. (Virtual keyboards are not supported yet.) If the console isn't registering your key presses, try pressing ++tilde++ a few times first, and ensure the game's window is focused.

If the console isn't showing up, try the following:

1. Try pressing ++tilde++ a few times (while ensuring the game's window is focused).
1. If that still doesn't work, the `world_scale` of your `XROrigin3D` may be too far away from `1`, so the console becomes too small to see. To mitigate this, try making the console 4x larger by adding this line to the script shown earlier:
    ```gdscript
    CrabbyConsole.eval_blocking(":cons vr scale 4")
    ```
    

!!! example "Experimental"

    VR support is experimental and subject to change. Mouse inputs are not supported yet, so you can only send keyboard events to the console.

## Resizing the console

As mentioned before, if you changed the `XROrigin3D`'s `world_scale` from its default value of `1`, the console may be too big or small. To fix that, you can run...
```
:cons vr scale 2
```
...to double the size of the console, or...
```
:cons vr scale 0.5
```
...to halve it.

### Expanding the console

Since there is no mouse support yet, the console may be too small vertically, and you can't drag the splitter to fix it. As a workaround, you can run this in the console:
```
:cons vr expand
```

Now the console will expand to fill all available vertical height.

## Camera follow

By default, the console will remain fixed in its position, regardless of where you look. To make the console follow the camera, run:
```
:cons vr follow 1
```

The console will now move with your head, so you can place it anywhere you want. To make it stop following you, run:
```
:cons vr follow 0
```

...and it will lock in place again.
