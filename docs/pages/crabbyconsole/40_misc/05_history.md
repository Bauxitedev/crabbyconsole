# History 

## Moving through history
Press ++up++ or ++down++ to move through commands you typed previously.

The history is stored in a `.csv` file in a subfolder in your game's userdata folder (`user://crabbyconsole/`). To open it you can run:

```
:open userdata
```

If you want to clear the history, you can delete the `history.csv` file in the `crabbyconsole` folder.

## History search
Press ++ctrl+r++ to toggle history search mode. You can then search for commands you typed previously - no need to memorize those pesky long commands anymore!
