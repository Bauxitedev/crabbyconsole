# CrabbyConsole Demo Project

This is a demo project demonstrates CrabbyConsole's abilities.

## Setup
There are two ways to set it up, you can pick either the easy way, or the hard way:

### Easy way
1. Download the latest version of CrabbyConsole from the [Releases page](https://github.com/Bauxitedev/crabbyconsole/releases).
2. Place the `addons` folder (from the downloaded zip file) in the root of the repo, overwriting it.

### Hard way
Compile CrabbyConsole yourself from scratch. [Follow the instructions in section "Compiling" here](https://bauxitedev.github.io/crabbyconsole/crabbyconsole/40_misc/45_development/).
